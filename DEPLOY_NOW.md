# Deploy Now!

Your Autism Support System is ready for deployment with CI/CD. Follow these steps to get your application live:

## 🚀 Quick Deployment Steps

### 1. Fork This Repository
- Go to GitHub and fork this repository to your account

### 2. Choose Your Hosting Platform

#### Option A: Vercel (Recommended)
1. Go to [vercel.com](https://vercel.com)
2. Sign in with your GitHub account
3. Click "New Project" → "Import Git Repository"
4. Select your forked repository
5. Configure as follows:
   - Framework Preset: `Other`
   - Root Directory: `.`
   - Build Command: `bash build_files.sh`
   - Output Directory: `staticfiles_build`
   - Install Command: `pip install -r requirements.txt`
6. Add environment variables:
   - `DJANGO_SECRET_KEY`: Paste the key generated by setup script
   - `DEBUG`: `False`
   - `EMAIL_HOST_USER`: Your email address
   - `EMAIL_HOST_PASSWORD`: Your email app password

#### Option B: Heroku
1. Go to [heroku.com](https://heroku.com)
2. Create an account and install the Heroku CLI
3. Create a new app
4. Go to Deploy tab → Connect to GitHub
5. Search for your forked repository
6. Enable Automatic Deploys
7. Go to Settings → Config Vars and add:
   - `DJANGO_SECRET_KEY`: Paste the key generated by setup script
   - `DEBUG`: `False`
   - `EMAIL_HOST_USER`: Your email address
   - `EMAIL_HOST_PASSWORD`: Your email app password

#### Option C: Railway
1. Go to [railway.app](https://railway.app)
2. Sign in with your GitHub account
3. Click "New Project" → "Deploy from GitHub repo"
4. Select your forked repository
5. Go to Settings → Environment Variables and add:
   - `DJANGO_SECRET_KEY`: Paste the key generated by setup script
   - `DEBUG`: `False`
   - `EMAIL_HOST_USER`: Your email address
   - `EMAIL_HOST_PASSWORD`: Your email app password

### 3. Alternative: Use GitHub Actions (Advanced)

If you prefer to use GitHub Actions for deployment:

1. Go to your GitHub repository → Settings → Secrets and Variables → Actions
2. Add the required secrets for your chosen platform (see DEPLOYMENT_GUIDE.md)
3. Push your code to GitHub to trigger the workflow

## 🔐 Security Notes

- The Django secret key was generated when you ran the setup script
- Never share your environment variables publicly
- Use app passwords for Gmail, not your regular password
- Change the email settings to your own email
